## Engineering principles

- Model the real workflow—including failure cases—before writing code.
- Keep authorization, secrets, and data ownership explicit.
- Prefer understandable components and stable interfaces.
- Treat documentation, testing, deployment, and error handling as product features.
- Ship useful software, measure what works, and improve from evidence.
